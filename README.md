# voice-automute

Claude の音声入力(Claude Code の `/voice`、Claude デスクトップ)で**録音している間だけ**、他のアプリの音を自動でミュートします。録音が終わると 0.3 秒後に元へ戻ります。PC の音がマイクに混ざって文字起こしされるのを防ぐためのツールです。

## 仕組み

1. 約 40ms ごとに、マイクの録音セッション(Windows Core Audio)を見ます。
2. **`claude.exe` が録音中(ACTIVE)になったときだけ**、他アプリの再生セッションをミュートします。
3. 録音が終わって 0.3 秒たつと、自分でミュートしたものだけ元に戻します。最初から手動でミュートしてあったものは触りません。

## 影響範囲(意図的に狭くしています)

- きっかけになるのは `claude.exe`(Claude Code / Claude デスクトップ)の録音だけです。Discord、Chrome、OBS、ゲームのマイク使用では何も起きません。
- `claude.exe` 自身の再生セッションはミュートしません。Claude の読み上げは聞こえます。
- 音声データは読みません。保存も送信もしません。ネットワーク接続も、外部プロセスの起動もありません。
- 1回の連続ミュートは最長 300 秒です。それを超えると自動で元に戻します。

## インストール / アンインストール

```powershell
.\install.ps1     # venv 作成、依存導入、ログイン時の自動起動を登録、今すぐ起動
.\uninstall.ps1   # 自動起動の解除、停止、ミュートの取り残しの復旧
```

管理者権限は不要です。

## 異常終了したとき

ミュートする前に、対象アプリ名を `%LOCALAPPDATA%\voice-automute\state.json` へ書き出します。強制終了やクラッシュでミュートが残っても、次回起動時に自動で解除します。名前を特定できないプロセスのセッションは、そもそもミュートしません。手動でやるなら次のコマンドです(ウォッチャーが動いていても実行できます)。

```powershell
.\.venv\Scripts\python.exe -I .\automute.py --restore
```

注意: 復旧はセッション単位ではなく**アプリ名単位**です。クラッシュ後の復旧では、その名前のセッションが手動でミュートされていた場合も解除されます。通常の動作(録音の開始〜終了)では、手動でミュートしたものには触りません。

## セキュリティ上の注意

- 管理者権限なし、ネットワークなし、外部プロセスの起動なしで、現在のユーザーのログイン中だけ動きます。
- 録音の判定は**実行ファイル名**(`claude.exe`)だけで行います。同じユーザーで動く別のプログラムが `claude.exe` という名前を名乗ると、最大 300 秒の間ほかのアプリの音を消せます。ただし同じユーザーのプログラムなら音量操作を直接できるので、新しい権限は増えません。発動時はログにプロセスのフルパスが残ります。
- 依存パッケージはバージョンとハッシュで固定し、`--require-hashes --only-binary=:all:` で入れます。ハッシュは Windows x64 用のホイールのものです。更新するときは `requirements.txt` のハッシュも作り直してください。
- 状態ファイルは 64KB までしか読まず、壊れた内容や不正な内容は無視して削除します。
- 実行は `python -I`(隔離モード)です。環境変数 `PYTHONPATH` や作業フォルダの同名モジュールは読み込みません。

## オプション

`python automute.py --help` を参照してください。主なものは次のとおりです。

- `--dry-run`: 何も変えず、ミュートする予定の対象だけログに出します。
- `--target EXE`: きっかけになる実行ファイル名を変えます(テスト用)。
- `-v`: 詳細ログ。

ログは `%LOCALAPPDATA%\voice-automute\automute.log` にあります(512KB × 3 世代でローテーションします)。
